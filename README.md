# Faithtabliberal
Website for Faith Tabernacle Church in Liberal, KS

## Pages:
  Home
  About
  Watch Sermons
    Sermon posts
  What We Believe
  Events

## Layouts:
  There is html layouts to create pages in markdown with Jekyll
    -Default: is the <head> info and Navigation
    -Page: includes Default layout with basic structure for other pages in the website
    -Watch: is the landing page for watching sermons
    -Sermon Post: is the html layout for individual posts
